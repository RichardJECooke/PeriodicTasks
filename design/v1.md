### Actions use can perform

- Open tasks file
- Save tasks file

- Tasks
  - Add task
  - Task list
  - Mark as done today
  - Edit
    - Name
    - Repeats every x days
    - Archive task
    - Stop editing
    - Date completed list
      - Change date
      - Delete date completed
- Archived tasks
  - List
  - Unarchive
  - Delete
- Toasts
  - Saved
  - Error
